# সরকার বংশ — অলুয়া, ব্রাহ্মণপাড়া, কুমিল্লা

বংশের সবার জন্য ওয়েবসাইট: বংশবৃক্ষ, প্রত্যেকের নিজের পেইজ, স্মরণ, খেলা আর এডমিন প্যানেল।
**React + Vite** (সামনের অংশ) আর **Supabase** (লগইন, ডাটাবেস, ছবি)। হোস্টিং **Vercel**-এ।

## পেইজগুলো
| পেইজ | কী আছে |
|---|---|
| হোম | পরিচিতি, সবার ছবির চলমান সারি, আজকের আমল, এই মাসের জন্মদিন, এই মাসে যাঁদের হারিয়েছি, তিন শাখা, প্রবীণদের কথা, আজকের পূর্বপুরুষ |
| পূর্বপুরুষ | মৈধর আলী ও তাঁর সন্তানদের শাখা, প্রতিটি শাখার গাছ |
| বংশবৃক্ষ | পুরো গাছ (শাখা গুটিয়ে রাখা যায়), নাম খোঁজা, স্বামী-স্ত্রী একসাথে, মেয়ের ঘরের সন্তানও |

## চালু করার ধাপ

### ১. Supabase
1. [supabase.com](https://supabase.com)-এ নতুন প্রজেক্ট খুলুন (Region: Singapore কাছাকাছি)।
2. **SQL Editor** → `schema.sql` পুরোটা পেস্ট করে **Run**।
3. আবার **SQL Editor** → `seed.sql` পেস্ট করে **Run** (বংশের প্রথম পুরুষ মৈধর আলী ও তাঁর তিন সন্তান যোগ হবেন; বাকিদের সাইট থেকে যোগ করবেন)।
4. **Project Settings → API** থেকে `Project URL` আর `anon public` key কপি করুন।
5. **Authentication → URL Configuration**-এ Site URL হিসেবে আপনার সাইটের ঠিকানা দিন (পরে Vercel-এর লিংক)।

### ২. কম্পিউটারে চালানো
```bash
cp .env.example .env      # তারপর .env-এ URL আর key বসান
npm install
npm run dev               # http://localhost:5173
```

### ৩. নিজেকে এডমিন বানানো
সাইটে "লগইন → নতুন একাউন্ট" দিয়ে একাউন্ট খুলুন। তারপর Supabase SQL Editor-এ:
```sql
update profiles set role = 'admin' where email = 'আপনার@email.com';
```
পেইজ রিফ্রেশ করলে উপরে "এডমিন" ট্যাব আসবে।

### ৪. অনলাইনে তোলা (Vercel)
1. কোডটা একটি **প্রাইভেট** GitHub রিপোতে রাখুন।
2. [vercel.com](https://vercel.com) → New Project → রিপো বেছে নিন।
3. Environment Variables-এ `VITE_SUPABASE_URL` আর `VITE_SUPABASE_ANON_KEY` দিন → Deploy।

## সদস্যরা কীভাবে যুক্ত হবেন
1. সাইটে একাউন্ট খুলবেন → "আমার পেইজ" চাপবেন।
2. তালিকায় নাম থাকলে নিজের পেইজে গিয়ে **"🙋 এটা আমি"** চাপবেন → এডমিন অনুমোদন দিলে নিজের তথ্য, ছবি, ফোন নিজেই বদলাতে পারবেন।
3. নাম না থাকলে নতুন পেইজ বানাবেন, বা কারো পেইজ থেকে **"➕ সন্তান যোগ করুন"** দিয়ে নতুন শিশুর নাম দেবেন → এডমিন অনুমোদন দিলে বংশবৃক্ষে আসবে।

## মেয়ের ঘরের সন্তান ও মায়ের বংশ
- জামাই বা বউমাকে এডমিন "বাইরের পরিবারের মানুষ" হিসেবে যোগ করবেন, তারপর স্বামী/স্ত্রী জুড়ে দেবেন।
- মেয়ের সন্তানের **মা** = বংশের মেয়ে, **বাবা** = জামাই। গাছে সন্তান মায়ের নিচে বসবে।
- মায়ের দিকের মানুষ (নানা) যোগ করলে পেইজে "মায়ের বংশ" দেখাবে, খেলায় মামা/খালা/মামাতো সম্পর্কও চিনবে।

## নিরাপত্তা ও গোপনীয়তা
- সাধারণ সদস্য শুধু নিজের পেইজ বদলাতে পারেন; বাবা-মা বা বংশের কাঠামো শুধু এডমিন বদলাতে পারেন (ডাটাবেস নিজেই আটকায়)।
- ফোন নম্বর শুধু লগইন করা সদস্যরা দেখেন, সাধারণ ভিজিটর নয়।
- প্রতিটি বদল ও মোছা ইতিহাসে জমা থাকে; এডমিন পেইজ থেকে আগের অবস্থায় ফেরানো যায়।

## ৫০ বছর টিকিয়ে রাখার জন্য
- **ব্যাকআপ:** এডমিন → ব্যাকআপ থেকে মাসে একবার নামিয়ে দুই-তিনজনের কাছে রাখুন।
- **একাধিক এডমিন:** প্রতিটি শাখা থেকে অন্তত একজন।
- **ডোমেইন** কয়েক বছরের জন্য একসাথে কিনুন, নবায়নের ইমেইলে আরেকজনকে যুক্ত রাখুন।
- **Supabase ফ্রি প্রজেক্ট** অনেকদিন ব্যবহার না হলে বিরতিতে (pause) চলে যেতে পারে; নিয়মিত ব্যবহার করুন বা পেইড প্ল্যানে যান। (এই নিয়ম বদলাতে পারে, Supabase-এর সাইটে দেখে নিন।)
- কোড ও GitHub রিপোতে আরেকজন বিশ্বস্ত সদস্যকে অ্যাক্সেস দিন।
